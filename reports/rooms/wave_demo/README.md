# The wave solver and a material per wall: a listening demo

Generated by `scripts/room_wave_demo.py` (docs/ROOM_LOOP_PLAN.md R7, R10). The kick, the bass
(an amp on the floor) and the piano of David Tyo's "Long Way Home" (Cambridge-MT multitrack:
educational use, never committed), recorded by a spaced pair of clean small omnis out in the
room, panned hard left and right: the room as the bass hears it.

Every `room_pair.wav` is at -18 LUFS: turn nothing up or down between them. `dry.wav` is the
three stems summed, no room.

| Folder | Room | Below 500 Hz |
|---|---|---|
| `small_geometric/` | 4.2 x 3.4 x 2.5 m, furnished | the geometric model (image sources + ray-traced tail) |
| `small_wave/` | the same | the wave solver (the room's modes) |
| `shoebox_geometric/` | 7 x 5.5 x 3.2 m, furnished (R5's live room) | the geometric model |
| `shoebox_wave/` | the same | the wave solver |
| `shoebox_dead_front/` | the same, drapes on the wall behind the players, plaster behind the pair (R7) | the wave solver |
| `small_trapped/` | the small room treated from physics: 100 mm wool spaced 100 mm off both side walls, a plywood panel bass trap behind the pair | the wave solver |

**Listen for**

- `small_geometric` against `small_wave`: the small room's bass. The geometric model gives the
  room's *average* low end (a statistically right level, smooth); the wave solver gives what
  this room does at these two mic positions: the modes at 41, 50 and 65 Hz ring, some bass notes
  bloom and others thin out. In the raw prints the wave solver is +5 to +14 dB at 25-125 Hz
  (loudness-matched, the rest of the spectrum sits correspondingly lower: compare the kick's
  thump with its click).
- `shoebox_geometric` against `shoebox_wave`: the same in the bigger room, less extreme (its
  modes are denser): +4 to +12 dB below 100 Hz, the 250-500 Hz region shuffled by a few dB.
- `shoebox_wave` against `shoebox_dead_front`: the same room with the wall behind the players
  dead and the one behind the mics live: the players' sound reaches the pair more from behind
  it, the front reflections gone; the mids and highs drier (RT at 1 kHz 0.78 -> 0.65 s) but
  the bass *longer* (125 Hz: 0.52 -> 0.74 s): the plaster wall reflects the low end the
  furnished one absorbed. Uneven treatment changes the balance, not just the amount.

- `small_wave` against `small_trapped`: the same small room treated with absorbers whose
  absorption comes from their construction (`varimu/rooms/materials.py`: Miki's porous model,
  a mass-spring panel): every band decays faster (125 Hz 0.34 -> 0.25 s, 500 Hz 0.56 -> 0.38
  s): a tighter, drier room, the modes still there but shorter. (Plywood traps on whole walls
  alone made the room livelier above 250 Hz: they reflect the mids the furnished walls
  absorbed. Real control rooms pair them with porous panels, as here.)

`levels.png` / `levels.json`: each variant's third-octave levels at the pair (loudness-matched).

How it is made: below 500 Hz each source's response comes from a finite-difference solution
of the wave equation on the GPU (a 3.4 cm grid, ~3 million cells in the shoebox, one run per
octave band with that band's wall admittance; ~1.5 s per run on the RTX 3080), blended with
the geometric model above (`varimu/rooms/wave.py`; checked against exact image sources in a
rigid box within -38 dB and against a 0.6 s image model of the same walls within +-0.5 dB).
